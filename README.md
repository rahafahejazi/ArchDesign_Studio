## Project Description

ArchDesign Studio is an architectural design application that allows users to create and explore house layouts based on their design ideas. Users can enter information such as the square footage, number of floors, and rooms they want in their house.

The goal of this project is to make the early stages of house planning easier by giving users a way to organize their ideas and visualize a possible design. The application is intended for people interested in architecture, including students, beginners, and anyone who wants to explore house design.

---

## How Does It Work?

The application is designed to take the user's information and use it to create a house layout.

```text
User enters house information
          ↓
The application processes the input
          ↓
A house layout is generated
          ↓
The user views and explores the design
```

| Input | Purpose |
|---|---|
| Square footage | Sets the approximate size of the house |
| Number of floors | Determines how many levels the house has |
| Number of rooms | Helps organize the house layout |
| Bathrooms | Adds bathroom requirements to the design |

---

## Main Features

- Enter the desired square footage of a house.
- Choose the number of floors.
- Add room requirements.
- Create a 2D floor plan.
- Explore a 3D version of the house design.

## How Did the Idea Come About?

I chose this project because I am interested in architecture and architectural engineering. I wanted to create something connected to a field I might want to pursue in the future.

I also wanted to challenge myself by creating an application that could be useful for people interested in designing houses. Instead of only drawing a floor plan, I wanted to explore how an application could turn basic information into a design that users could understand and visualize.

## Challenges

### Learning Java

One of my biggest challenges was working with Java and understanding how to organize the code. I had to learn how different parts of the application connect and how to fix problems when the code did not work as expected.

### Setting Up the Application

Getting the application to run correctly in GitHub Codespaces took time. I experienced issues with the Java configuration, the main class, and the ports. I had to troubleshoot these problems before I could successfully open the application in my browser.

### Debugging and Testing

Another challenge was making sure the application worked after making changes. I had to test the application, look for errors, and make adjustments until it opened correctly.
